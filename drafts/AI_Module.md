# AI 功能模块规范

1. **新建模块时**：
    - 必须先在 `.ai/blueprints/modules/` 下创建 `[module_name].md`。
    - 必须严格按照模块方案模板（定位、接口、内部设计、依赖、变更历史）进行描述。
    - 接口定义必须 100% 与即将编写的真实代码（TS 类型/Go 结构体等）一致。

2. **重构或变更模块时（同步机制）**：
    - 当用户要求修改某个模块的功能时，首先读取对应的 `[module_name].md`。
    - **严禁直接改代码**。必须先在 `[module_name].md` 的 `## 5. 变更历史` 中追加一条记录，写明变更理由与接口变化。
    - 检查该模块方案中的 `## 4. 依赖项与影响范围`，主动向用户或通过 Agent 检查所有受影响的联动模块，确保整体不报错。
    - 方案更新后，再一键应用（Apply）代码修改。
